# Denis Samatov

**Machine Learning Engineer & Technical Lead · LLM/RAG · Document Intelligence · Scientific ML**

I build and evaluate software for document-heavy workflows and scientific data. My public work focuses on permission-aware MCP integrations, traceable retrieval systems, and reproducible research code.

## Start here

| Project | What you can inspect or run |
| --- | --- |
| [yandex-workspace-mcp](https://github.com/denis-samatov/yandex-workspace-mcp) | An MCP integration for Yandex Disk and Wiki. Start with the [offline permission demo](https://github.com/denis-samatov/yandex-workspace-mcp/blob/main/examples/permission_demo.py) to inspect tool access without connecting an account. |
| [mcp-capguard](https://github.com/denis-samatov/mcp-capguard) | A pytest plugin and CLI for checking which MCP tools each configuration profile exposes. The [FastMCP example](https://github.com/denis-samatov/mcp-capguard/tree/main/examples/fastmcp_example) demonstrates a permission regression. |
| [tensor-based-modal-decomposition-method](https://github.com/denis-samatov/tensor-based-modal-decomposition-method) | Tensor-based modal decomposition and sparse sensor placement. The repository includes [a captured synthetic run](https://github.com/denis-samatov/tensor-based-modal-decomposition-method/blob/main/docs/examples/synthetic-run.md) and explains the limits of reproducing the manuscript results. |
| [llm-adviser-case-study](https://github.com/denis-samatov/llm-adviser-case-study) | A sanitized architecture case study on document processing, retrieval, evaluation, and reliability. The application source remains private. |

The first two projects show reusable integration and testing code. The tensor project shows research software and reproducibility work; the case study shows system design where source publication is constrained.
