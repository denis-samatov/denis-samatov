## Featured Work

### EPIFAT — Epicardial Fat Segmentation & Radiomics

**Problem:** Manual analysis of epicardial adipose tissue on cardiac CT scans is time-consuming and difficult to standardize.

**Approach:** Automated segmentation and quantitative radiomic feature extraction for cardiac CT image analysis.

**Tech stack:** Python, PyTorch, U-Net, Attention U-Net, OpenCV, PyRadiomics.

**Outcome:** State-registered software module for automatic segmentation of epicardial adipose tissue: **Rospatent No. 2025610317, 2025**.

---

### Radiomics for Cardiovascular Imaging

**Problem:** Cardiovascular image analysis requires reproducible quantitative feature extraction and ML-based assessment.

**Approach:** Segmentation of myocardial polar maps, radiomic feature extraction and patient classification experiments.

**Tech stack:** Python, Jupyter, U-Net, K-means, Otsu thresholding, PyRadiomics, classical ML models.

**Repository:** [denis-samatov/radiomics](https://github.com/denis-samatov/radiomics)

---

### Tensor-Based Methods for Reservoir Modeling

**Problem:** High-dimensional spatio-temporal simulation data is expensive to store, analyze and reconstruct.

**Approach:** Tensor decomposition and low-dimensional representations for scientific data analysis and reservoir modeling.

**Tech stack:** Python, NumPy, TensorLy, scientific computing, tensor methods.

**Outcome:** Research work focused on dimensionality reduction and efficient representation of reservoir simulation data.

---

### HR Analytics — Salary Forecasting System

**Problem:** Salary monitoring and forecasting require automated collection, cleaning and analysis of labor market data.

**Approach:** Web service for collecting, processing and forecasting salary data from HeadHunter API sources.

**Tech stack:** Python, Flask, FastAPI, Playwright, Docker, Celery, Redis.

**Outcome:** Applied analytics system for salary monitoring, forecasting and data-driven labor market analysis.

---

### OCR / Table Extraction from Financial Reports

**Problem:** Financial reports often contain tabular data in PDF or image formats that must be converted into structured data.

**Approach:** Computer vision and OCR pipeline for detecting table structure and exporting extracted content into CSV.

**Tech stack:** Python, OpenCV, PyMuPDF, Tesseract OCR, NumPy, Matplotlib.

**Repository:** [denis-samatov/recognition_russian_financial_reports](https://github.com/denis-samatov/recognition_russian_financial_reports)
